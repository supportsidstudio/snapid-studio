# SnapID Studio - Dress / Suit Templates

Place your transparent PNG suit templates in this directory.

Supported filenames:
- `men_black_suit_tie.png`
- `men_navy_suit_tie.png`
- `men_charcoal_suit_tie.png`
- `men_black_suit_notie.png`
- `men_bandhgala_suit.png`
- `men_blue_formal_shirt.png`
- `women_black_business_blazer.png`
- `women_navy_corporate_suit.png`
- `women_formal_white_shirt.png`
- `women_formal_saree_maroon.png`
- `women_charcoal_blazer.png`
- `kids_school_navy_blazer.png`
- `kids_black_formal_suit.png`
- `kids_white_collar_shirt.png`

Any template without an explicit PNG file automatically uses the high-definition vector SVG fallback template or any custom PNG uploaded through the UI.
